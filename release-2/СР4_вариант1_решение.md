# Самостоятельная работа №4. Интервальные оценки параметров распределения. Вариант 1

## Часть 1. Теоретические вопросы

**1. Точечная и интервальная оценка.**
Точечная оценка — одно число, посчитанное по выборке, которое берут как приближённое значение параметра (например, x̄ для a). Интервальная оценка — два числа, границы промежутка, который с заранее выбранной вероятностью содержит истинное значение параметра.
Главный недостаток точечной оценки: она не показывает, насколько может ошибаться. При малом n случайная выборка может дать значение, заметно отличающееся от истинного параметра, а по самому числу этого не видно.

**2. Точность оценки ε и доверительная вероятность γ.**
ε > 0 — точность оценки (предельная ошибка): максимально допустимое отклонение |θ* − θ|.
γ — доверительная вероятность (надёжность), то есть вероятность выполнения неравенства |θ* − θ| < ε: P(|θ* − θ| < ε) = γ. Берут обычно 0,95; 0,99; 0,999.
На практике: ε — «плюс-минус» вокруг оценки, γ — степень уверенности, что этот коридор накрыл параметр. Доверительный интервал: (θ* − ε; θ* + ε).

**3. «Интервал накрывает параметр».**
Параметр θ — фиксированное неизвестное число, случайным он не является. Случайны границы интервала, так как они считаются по случайной выборке. Поэтому вероятность относится к интервалу: интервал накрывает θ с вероятностью γ. При многократном повторении выборок примерно 100·γ % построенных интервалов накроют θ.

**4. Роль ЦПТ (теоремы Ляпунова).**
Для x̄ имеем M(x̄) = a, σ(x̄) = σ₀/√n. Если X нормально распределена, то и x̄ нормальна. Если закон X неизвестен, по теореме Ляпунова нормированная сумма (x̄ − a)/(σ₀/√n) при росте n стремится к N(0;1) (на практике при n ≥ 30). Это позволяет использовать функцию Лапласа и формулу P(|x̄ − a| < ε) = 2Φ(ε√n/σ₀) = γ для построения интервала даже при неизвестном законе распределения.

**5. Формулы доверительного интервала для a при известном σ₀.**
Φ(t) = γ/2, t находят по таблице Лапласа.
- Повторный отбор: ε = t·σ₀/√n.
- Бесповторный отбор (объём совокупности N): ε = (t·σ₀/√n)·√(1 − n/N).

Интервал: x̄ − ε < a < x̄ + ε.

**6. Изменение ширины интервала и ε.**
Так как ε = t·σ₀/√n:
а) n увеличили в 4 раза → √n вырос вдвое → ε и ширина интервала (2ε) уменьшаются в 2 раза.
б) γ увеличили (0,90 → 0,99) → растёт Φ(t) = γ/2, значит растёт t (1,645 → 2,58), ε и интервал увеличиваются (в 2,58/1,645 ≈ 1,57 раза). Больше надёжности — меньше точность.

**7. Минимальный объём выборки.**
Из формул для ε выражаем n:
- повторный отбор: n = t²σ₀²/ε²;
- бесповторный отбор: n = t²σ₀²N / (ε²N + t²σ₀²).

Если n получилось нецелым, округляют **в большую сторону** до ближайшего целого (чтобы точность ε была гарантирована).

## Часть 2. Практические задачи

Алгоритм (лекция 4): Φ(t) = γ/2 → t по таблице Лапласа → ε = t·σ₀/√n → x̄ − ε < a < x̄ + ε.
Для γ = 0,95: Φ(t) = 0,475, по таблице t = 1,96.

### Задача 1
**Дано:** n = 16, σ² = 0,0016 → σ₀ = 0,04, γ = 0,95. Нормальное распределение, σ известно.

1. Сумма значений: 22,43 → x̄ = 22,43 / 16 = **1,401875**.
2. Φ(t) = 0,95/2 = 0,475 → t = 1,96.
3. ε = 1,96·0,04/√16 = 0,0784/4 = **0,0196**.
4. 1,401875 − 0,0196 < a < 1,401875 + 0,0196
   1,382275 < a < 1,421475

**Ответ:** a ∈ (1,382275; 1,421475) с надёжностью 0,95.

### Задача 2
**Дано:** n = 100, s = 6 (СКО, считаем σ₀ = 6), γ = 0,95.

1. Сумма значений: 494,1 → x̄ = 494,1 / 100 = **4,941**.
2. Φ(t) = 0,475 → t = 1,96.
3. ε = 1,96·6/√100 = 11,76/10 = **1,176**.
4. 4,941 − 1,176 < a < 4,941 + 1,176
   3,765 < a < 6,117

**Ответ:** x̄ = 4,941; a ∈ (3,765; 6,117).

### Задача 3
**Дано:** n = 100, s = 5 (σ₀ = 5), γ = 0,95.

1. Сумма значений: 3759,2 → x̄ = 3759,2 / 100 = **37,592**.
2. Φ(t) = 0,475 → t = 1,96.
3. ε = 1,96·5/√100 = 9,8/10 = **0,98**.
4. 37,592 − 0,98 < a < 37,592 + 0,98
   36,612 < a < 38,572

**Ответ:** x̄ = 37,592; a ∈ (36,612; 38,572).
